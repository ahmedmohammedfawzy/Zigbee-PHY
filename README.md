# CSS PHY Transmitter — IEEE 802.15.4 (Zigbee)

FPGA implementation of the IEEE 802.15.4 Chirp Spread Spectrum (CSS) PHY
transmitter, in synthesizable SystemVerilog, with a bit-exact MATLAB/Python
golden reference model used for verification.

The transmitter takes a raw payload (0–127 bytes) from a MAC layer, frames it
into a standard PPDU (preamble, SFD, PHR, PSDU), and outputs I/Q chirp-
modulated baseband samples. Both supported data rates — 1 Mb/s and
250 kb/s — are implemented.

## Verification Methodology

RTL correctness is checked against an independent, bit-exact golden reference
model — not the abstract floating-point spec, but a model that mirrors the
RTL's own arithmetic (integer phase-index DQPSK accumulation, add/sub chirp
rotation, exact bit ordering) so that a sample-for-sample diff is meaningful.
The golden model reads the same `.mem` ROM files the RTL instantiates.

### Full-chain integration (`tb_tx_top.sv`)

| Case | Rate | Payload | Samples | Result |
|---|---|---|---|---|
| 1 | 1 Mb/s | 20 bytes | 7,842 | PASS |
| 2 | 250 kb/s | 5 bytes | 13,824 | PASS |
| 3 | 1 Mb/s | 0 bytes (edge) | 2,850 | PASS |
| 4 | 1 Mb/s | 127 bytes (max, edge) | 35,328 | PASS |

**59,844 total I/Q sample-pairs compared, 0 mismatches**, across both data
rates and both required payload-length boundaries.

### Unit-level tests

| Block | Coverage | Result |
|---|---|---|
| `zero_padder` | Exhaustive sweep, all 128 payload lengths, both rates | PASS |
| `bit_interleaver` | Structural + full 64-bit single-impulse sweep + random | 93/93 PASS |
| `dqpsk_encoder` | Wraparound, mid-packet reset, handshake stalls | 83/83 PASS |

### A real bug, caught and fixed

During verification, the 250 kb/s full-chain case initially **failed**
(2,664/13,824 mismatches) due to a symbol-ordering bug — traced to the
*golden reference model*, not the RTL. See the full pass/fail transcript with
root-cause analysis in [`build/README_FAIL.md`](build/README_FAIL.md) and
[`build/README_PASS.md`](build/README_PASS.md).

## Running the Simulations

Requires ModelSim (tested on ModelSim - Intel FPGA Edition, 2020.1).

```bash
cd build

# compile
vlog ../rtl/*.sv ../tb/*.sv

# full-chain integration test
vsim -c -voptargs=+acc work.tb_tx_top -do "run -all; quit -f"

# unit tests
vsim -c -voptargs=+acc work.tb_bit_interleaver -do "run -all; quit -f"
vsim -c -voptargs=+acc work.tb_dqpsk_encoder -do "run -all; quit -f"
vsim -c -voptargs=+acc work.tb_zero_padder -do "run -all; quit -f"
```

`tb_tx_top.sv` requires golden reference CSVs (`golden_tx_iq*.csv`) to be
present in `build/` — these are generated by the MATLAB/Python golden model
and are checked in alongside the transcripts for reproducibility.

To regenerate a golden CSV for a new test case, edit the payload/rate/chirp
index parameters at the top of `matlab/css_verify_golden.m` and run it in
MATLAB (requires Fixed-Point Designer), or use the Python port for faster
iteration.
