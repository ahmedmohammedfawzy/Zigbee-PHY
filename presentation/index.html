Design challenge

Zero padding began as a direct modulo equation

base_bits = 12 + 8L
pad_bits = N − (base_bits mod N)
N = 6 at 1 Mb/s, N = 24 at 250 kb/s

Functional requirement

Each frame must end on the mapper or interleaver block boundary.

Important edge case

When the frame already aligns, the MATLAB behavior appends one complete block rather than zero bits.

Source: matlab/transmitter/ChirpSpreadSpectrum_Tx.m, rtl/zero_padder.sv

First implementation

A literal modulo operator hid expensive hardware

Initial expression

rem = base_bits % N; pad = N - rem;

Division by a non-power-of-two constant can create a larger arithmetic network and a longer combinational path.

Observation

3

Both rates repeat the same padding pattern every three payload bytes.

Optimization question: can payload length modulo 3 select the final pad directly?

Design issue described by the team; optimized RTL in rtl/zero_padder.sv

Differential encoding

DQPSK is modulo-4 phase addition with a four-symbol delay

A two-bit pointer walks through four phase registers. Packet start resets every tap to the π/4 baseline code.

Natural modulo arithmetic

The two-bit addition wraps automatically after phase code 3.

Handshake behavior

The feedback memory advances only when valid input meets downstream ready.

11 / 16
Phase-domain representation

Four diagonal states replace signed complex symbols

00 · π/4
01 · 3π/4
10 · 5π/4
11 · 7π/4

Cartesian form

Signed real and imaginary values, wider storage, complex multiplication, normalization concerns.

Phase form

Two bits per symbol, modulo addition, exact state encoding, direct add/sub selection.

The phase can take only four values. Storing general complex numbers would preserve precision the algorithm never uses.

Source: rtl/dqpsk_encoder.sv, rtl/csk_modulator.sv

Conclusion

The design maps the reference algorithm into hardware-friendly structures

Implemented

  • Two rate-dependent coding paths
  • Framing, padding, interleaving, and chirp output
  • Ready-aware phase pipeline

Key design choices

  • Six-case padding decode instead of general modulo arithmetic
  • Two-bit phase state instead of signed complex storage
  • Add/sub chirp modulation instead of complex multipliers
